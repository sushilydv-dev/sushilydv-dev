### About me

I'm a full stack developer who enjoys turning ideas into products people can use. I work across the whole stack: responsive front ends in **React** and **React Native**, APIs in **Node.js / Express** and **Python**, and data in **PostgreSQL, MySQL, MongoDB and Redis**. I care about clean code, fast interfaces and software that's easy to run and maintain. I also collaborate on open-source projects.

### What I do

| | |
|---|---|
| **Web applications** | Responsive, accessible interfaces with React, Tailwind CSS and Bootstrap, plus data visualisation with Chart.js |
| **Mobile apps** | Cross-platform apps with React Native |
| **APIs and back ends** | REST APIs with Node.js, Express and Python, with authentication, validation and testing in Postman |
| **Data** | Schema design and queries across PostgreSQL, MySQL, MongoDB, Redis and Firebase |
| **Computer vision** | Real-time image and video processing with OpenCV and Python |
| **Delivery** | Docker, Git workflows, Linux servers and CI/CD, from design files in Figma to production |
